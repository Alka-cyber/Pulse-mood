# Pulse Board

Pulse Board is a local-first daily wellbeing tracker. It stores entries in your browser, works without an account, and exports backup files you can keep in OneDrive, Google Drive, iCloud, or Dropbox.

## Open on laptop

Double-click:

```text
Start Pulse Board.cmd
```

If nothing opens, double-click:

```text
Open Pulse Board Offline.cmd
```

## Main views

- Entry: daily logging for backdated or current entries.
- Stats & Analytics: cluster plot, mood mix, energy mix, calendar, feed, and signals.

## Entry flow

1. Choose the date. You can pick a previous date to backfill missed days.
2. Pick one or more moods for Morning, Afternoon, Evening, and Night.
3. Add a slot note if useful.
4. Choose energy: Low, Normal, or High.
5. Add stress, sleep, water, mindful minutes, and walking steps.
6. Tick any habits or signals: Sunlight, Self critical, News, Periods, Crying, Listening music, Exercise / gym, Walks.
7. Add a daily note.
8. Click Save Entry.

Saved entries update the calendar immediately.

## Stats included

- Emotion cluster plot for week, month, and year.
- Mood mix pattern chart.
- Energy level mix.
- Metric trend bars for sleep, water, mindful minutes, and steps.
- Calendar with day emoji.
- Recent log feed.
- Richer signals from mood themes, difficult emotion share, energy, steps, and habits.

## Backup and restore

Click Backup to download a JSON backup file. Keep it in a cloud folder.

Click Restore to bring entries back from a backup file.

Click CSV to export a spreadsheet-friendly file for Excel or Google Sheets.

Previous app entries are migrated into the new format automatically when the app opens.

## Phone use

For phone installation, this folder needs an HTTPS link. You can publish it using GitHub Pages, Netlify, Vercel, or Cloudflare Pages. Open the link on your phone, then use Add to Home Screen or Install.
